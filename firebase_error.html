Firebase connection problems on Windows

Use this guide if the PC version of Imposter 3D cannot load your account, news, or other online data.

Important safety notice

Continue only if you understand the setting or command you are changing. Save or write down the original settings before making changes.

You perform these actions at your own risk. Snow Bat and the game developers are not responsible for system, network, or software changes you make, or for any consequences of those changes.

Do not download individual DLL files from third-party websites, do not permanently disable security software, and do not change settings on a work, school, or managed PC without permission from its administrator.

Test after every step. Fully close the game, open it again, and check whether the account and news load. If everything works, stop and do not perform the remaining steps.

  1. Check your Windows version

    1. Press Win + R.
    2. Enter winver and press Enter.
    3. Check the version shown in the window.

    The game requires Windows 10 version 1903 (OS build 18362) or newer. Windows 11 is supported. Windows 7, Windows 8, Windows 8.1, Windows 10 version 1809, and Windows 10 LTSC 2019 may be missing the system icu.dll library required by Firebase.

    If your version is older, install all available Windows updates or upgrade to a supported Windows version. Never download icu.dll separately.

  2. Install or repair Microsoft Visual C++ Runtime

    1. Download the official Microsoft Visual C++ Redistributable x64 .
    2. Run the downloaded installer.
    3. Select Install, or select Repair if it is already installed.
    4. Complete the installer and follow its restart request, if one appears.
    5. Open the game and test the account and news.

    The 64-bit Firebase libraries require MSVCP140.dll, VCRUNTIME140.dll, and VCRUNTIME140_1.dll. The official installer is the safe way to install or repair them.

  3. Compare your normal network with a mobile hotspot

    1. Fully close the game.
    2. Enable a mobile hotspot on your phone.
    3. Connect the PC to the hotspot instead of the usual Wi-Fi or Ethernet connection.
    4. Open the game and check the account and news.
    If Firebase works through the hotspot: the game and Windows libraries are probably working. The likely cause is your usual DNS, router, filtering software, or internet provider. Continue with the network steps below.
    If Firebase still does not work: reconnect to your normal network and continue with the next step. The cause may still be a PC-wide DNS/filter setting or damaged Windows components.

  4. Change DNS and clear the DNS cache

    First, write down the existing DNS setting so you can restore it later.

    1. Open Settings → Network & Internet.
    2. Open the properties of the active Wi-Fi or Ethernet connection.
    3. Find DNS server assignment and select Edit.
    4. Select Manual and enable IPv4.
    5. Enter either Cloudflare DNS: 1.1.1.1 and 1.0.0.1, or Google DNS: 8.8.8.8 and 8.8.4.4.
    6. Save the settings.
    7. Open Command Prompt and run:
    ipconfig /flushdns

    Open the game and test again. If this does not help, you may restore the original DNS setting.

  5. Check antivirus, ad blocking, and parental-control filtering

    Check AdGuard, NextDNS, Pi-hole, Kaspersky, ESET, antivirus web protection, parental controls, router filters, and similar software.

    1. Add the game executable (.exe) to the application's trusted or excluded apps.
    2. Exclude the game from HTTPS, SSL/TLS, encrypted-connection, or network-traffic inspection.
    3. Add these domains to the allowlist:
    identitytoolkit.googleapis.com
securetoken.googleapis.com
firebaseremoteconfig.googleapis.com
imposter-3d-eb94a-default-rtdb.europe-west1.firebasedatabase.app

    Keep the rest of your protection enabled. Close and reopen the game after saving the exclusions.

  6. Check for an unwanted Windows proxy

    1. Open Command Prompt.
    2. Run:
    netsh winhttp show proxy

    If it says Direct access (no proxy server), continue to the next step.

    If it shows a proxy that you intentionally use, do not remove it. If this is your personal PC and the proxy is unknown or no longer needed, open Command Prompt as administrator and run: 

    netsh winhttp reset proxy

    Also open Settings → Network & Internet → Proxy and disable a manual proxy only if you did not configure or need it.

  7. Test with a reputable VPN or Cloudflare WARP

    1. Fully close the game.
    2. Connect through a reputable VPN or Cloudflare WARP.
    3. Open the game and test Firebase.
    If Firebase works only with the VPN: your internet provider or network is probably filtering or incorrectly routing Google/Firebase traffic. Changing game files will not fix that. Contact the provider and report that Google API HTTPS connections are unavailable, or use a trusted encrypted connection. Avoid unknown free VPN applications.

  8. Inspect the Windows hosts file

    1. Open Notepad as administrator.
    2. Select File → Open.
    3. Open C:\Windows\System32\drivers\etc\hosts. You may need to select All files.
    4. Save a backup copy before editing.
    5. Look for active lines containing googleapis.com, firebase, or firebasedatabase.app.

    Remove or comment out only entries that you understand and that incorrectly redirect or block these services. Do not erase unrelated entries. Save the file, run ipconfig /flushdns, and test the game again.

  9. Repair Windows system files

    Use this step if Firebase also fails through another network and the earlier steps did not help.

    1. Search for Command Prompt.
    2. Right-click it and select Run as administrator.
    3. Run the first command and wait for it to finish:
    DISM.exe /Online /Cleanup-Image /RestoreHealth

    Then run:

    sfc /scannow

    Do not close the window before both checks finish. Install any pending Windows updates afterward, then test the game again.

  10. Send the diagnostic log to support

    If Firebase still does not work:

    1. Open the game and reproduce the problem once.
    2. Close the game.
    3. Press Win + R.
    4. Paste this path and press Enter:
    %USERPROFILE%\AppData\LocalLow\Snow Bat\Online Imposter 3D
    1. Find Player.log.
    2. Send it privately to snowbatstudio@gmail.com.
    3. Include your Windows version, whether the mobile hotspot or VPN worked, and the last step you completed.

    Do not publish Player.log in a public chat or forum because diagnostic logs may contain device or account identifiers.
